# 실내건축사례분석 × 프롬프트

『실내건축사례분석 X 프롬프트 : Interior Architecture Case Study Prompt』(김주연 지음) 웹 열람본.

- `index.html` : 책 뷰어 (표지가 열리며 시작, 클릭·←/→·스와이프로 넘김)
- `img/` : 표지·날개 이미지 (front = 앞표지, flap-front = 앞날개, flap-back = 뒷날개, back = 뒷표지)
- `img/pages/` : 속지 001–336 (열람본 PDF 5–340쪽, 웹용 WebP — 파일 번호가 책에 인쇄된 쪽 번호와 같음)
- `img/ring/` : 첫 화면 고리용 사례 이미지

속지를 바꾸려면 `img/pages/`의 같은 번호 파일을 교체하고, 쪽수가 달라지면 `index.html`의 `INNER_COUNT` 값을 고치면 됩니다.
